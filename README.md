# Recurve Score — Android Studio project

Offline score app for 4 archers, 4 turns each, 4 ends per turn, 3 arrows per end. X counts as 10. Scores and names save locally on the phone. No network permission is requested.

## Build an APK
1. Open this folder in Android Studio.
2. Allow Gradle sync (first build may need internet to download Android build tools).
3. Choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Copy the generated APK to your Android phone and install it.

The app works offline after installation. This ZIP contains the Android Studio project source, not a prebuilt APK.
